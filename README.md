# HireCode AI

> AI-powered technical interview platform with live coding, video meetings, and automated candidate evaluation.

---

## 🚀 About the Project

HireCode AI is a real-time collaboration platform designed for HR teams and interviewers
to conduct structured technical interviews.  
It combines video conferencing, a live code editor, and AI-based evaluation to help
hire better engineers with less bias.

---

## 🎯 Target Users

- HR professionals
- Technical interviewers
- Engineering hiring teams
- Job candidates (interview mode)

---

## ✨ Core Features (MVP)

- Real-time video & audio interviews (WebRTC)
- Live collaborative code editor
- Multi-language coding support
- AI-assisted code evaluation
- Automated interview feedback & summary

---

## 🛠 Tech Stack
